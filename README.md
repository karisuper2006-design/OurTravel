# ふたり · Япония вдвоём

Путеводитель на 7–15 мая 2027: Токио, Осака, Киото и Нара. 44 места, категории, избранное, расстояния от геопозиции и маршруты в Google Maps.

## Локальный запуск

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Откройте http://localhost:4173. Для геопозиции нужен HTTPS либо localhost и разрешение браузера.

## Публикация

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. После обновления файлов и `git push` сайт обновится автоматически.

Избранное сохраняется в браузере на устройстве. При смене адреса сайта избранное из прежнего адреса не переносится автоматически. Расстояния приблизительные, в метрах по прямой; путь рассчитает Google Maps. Без разрешения геопозиции расстояние не выдумывается.
